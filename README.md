# java-racingcar-precourse

## 구현할 기능적 사항
1. 입력을 받아서 ","로 자동차를 구분해야 한다.
2. 자동차의 전진 시도 횟수를 입력 받아야 한다.
3. 각 자동차의 시도는 무작위 한 자리 숫자중 4이상일 경우 전진한다.
4. 모든 시도가 끝나면 우승자를 판별해야 한다.

## 구현할 비기능적 사항
1. 사용자가 잘못된 값을 입력할 경우 예외를 발생시킨 후 앱을 종료해야 한다.

## 구현할 인터페이스 사항
1. 자동차들의 이름 입력 요청을 표시해야 한다.
```terminaloutput
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
```
2. 시도 횟수 입력 요청을 표시해야 한다.
```terminaloutput
시도할 횟수는 몇 회인가요?
```
3. 각 실행 결과를 표시해야 한다.
```terminaloutput
실행 결과
pobi : -
woni :
jun : -
```
4. 최종 우승자들을 ','로 구분하여 표시해야 한다.
```terminaloutput
최종 우승자 : pobi, jun
```
